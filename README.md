# Знижки — акції магазинів для iOS 6

Застосунок для iOS 6+ (Theos, MRC, armv7) + збирач акцій Сільпо, АТБ, Varus та Аврори.

## Як це працює

GitHub Actions кожні 4 години запускає `scripts/build.mjs`: він збирає акції з сайтів магазинів, розкладає товари по спільних категоріях, робить мініатюри 120×120 JPEG (iOS 6 не вміє WebP) і публікує все на GitHub Pages:

- `index.json` — магазини, категорії, лічильники, час оновлення
- `store/<id>.json` — товари магазину, відсортовані за знижкою (до 150 на категорію)
- `img/<id>/<hash>.jpg` — мініатюри

Застосунок читає ці файли. Власного сервера не потрібно.

## Джерела

| Магазин | Звідки | Дата завершення |
|---|---|---|
| Сільпо | JSON API `sf-ecom-api.silpo.ua` (товари з промо, де є стара ціна) | — |
| АТБ | HTML сторінок «Економія», «Суперціна», «Вигода з АТБільше» | є |
| Varus | JSON API каталогу (Vue Storefront) | є |
| Аврора | HTML каталогу з фільтром «Товари зі знижками» | — |

Якщо якийсь магазин не відповідає (блок, зміна сайту), збирач бере його попередні дані з Pages і позначає як застарілі — решта магазинів оновлюється як завжди.

**Новий магазин** = файл у `scripts/sources/` з функцією `fetchItems()`, що повертає `{id, t, p, o, u, c, e, img, l}`, + рядок у `SOURCES` в `build.mjs`. Магазини на платформі Zakaz.ua (Novus, ЕКО маркет, Ашан, Metro…) підключаються однаково через `stores-api.zakaz.ua`, але там акції прив'язані до конкретного магазину/міста.

## Категорії

`scripts/categories.mjs` — 16 спільних категорій і класифікатор за ключовими словами: спершу категорія магазину, потім назва товару. Для Сільпо — за коренем дерева категорій. Для непродуктових магазинів (Аврора) спершу перевіряються непродуктові групи, щоб «Гарбуз» на свічнику не потрапив в овочі.

## Застосунок

Встанови `Znyzhky.ipa` через 3uTools (є і на сторінці Pages).

- **Усі** — усі акції: пошук, сортування за знижкою / ціною / «закінчуються», фільтр «від N%»
- **Магазини** — кількість акцій, середня та максимальна знижка по кожному
- **Категорії** — 16 груп з емодзі
- **Обране** — товари із зірочкою + слова для відстеження («кава», «Nivea»): бейдж на вкладці показує, скільки таких товарів зараз в акції
- **Ще** — вмикання/вимикання магазинів, мінімальна знижка, адреса сервера

Офлайн-кеш даних і мініатюр, pull-to-refresh.

### Збирання (WSL)
```bash
cd app && make package FINALPACKAGE=1
```
`.ipa` з'явиться в `app/packages/`.

### Локальний прогін збирача
```bash
npm install
node scripts/build.mjs          # результат у public/
NO_IMAGES=1 node scripts/build.mjs   # без мініатюр, швидко
```
